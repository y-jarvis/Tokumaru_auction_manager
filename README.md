# ヤフオク販売管理 自動化システム

ヤフオクの出品〜落札までの履歴を、Gmail × Google Apps Script (GAS) で自動的にスプレッドシートへ記録するシステムです。

## 機能

- **出品完了メール** → スプレッドシートに新規行を自動追加
- **入札通知メール** → 現在価格・入札数を自動更新
- **落札通知メール** → 落札価格・落札者・ステータスを自動更新
- **終了通知（未落札）** → ステータスを「未落札」に自動更新
- **過去メール一括インポート** → 既存のヤフオクメールを一括で取り込み

## セットアップ手順

### 1. ユーザー事前作業

#### Yahoo! JAPAN 設定
- [ ] Yahoo! JAPAN IDの連絡先メールアドレスをGmailに変更
  - Yahoo! JAPAN → 登録情報 → 連絡先メールアドレス変更

#### ヤフオク通知設定
以下の通知がONであることを確認：
- [ ] 出品完了通知
- [ ] 入札通知
- [ ] 落札通知
- [ ] オークション終了通知

#### Gmail フィルタ設定
- [ ] フィルタを作成
  - From: `@mail.yahoo.co.jp`
  - アクション: ラベル「ヤフオク」を付与

### 2. スプレッドシート準備

- [ ] Google スプレッドシートを新規作成
- [ ] スプレッドシートのURLからIDを取得
  - URL: `https://docs.google.com/spreadsheets/d/【このIDをコピー】/edit`

### 3. GAS プロジェクトセットアップ

#### clasp のインストール（初回のみ）

```bash
npm install -g @google/clasp
clasp login
```

#### プロジェクト作成

```bash
# GAS プロジェクトを新規作成
clasp create --type standalone --title "ヤフオク販売管理"

# .clasp.json が生成されるので、rootDir を設定
# .clasp.json の内容:
# {
#   "scriptId": "自動生成されたID",
#   "rootDir": "./src"
# }
```

### 4. 設定変更

`src/config.gs` を編集し、スプレッドシートIDを設定：

```javascript
SPREADSHEET_ID: 'あなたのスプレッドシートID',
```

### 5. デプロイ

```bash
# GAS にコードをプッシュ
clasp push

# GAS エディタをブラウザで開く
clasp open
```

### 6. 初回実行

GAS エディタ上で以下の関数を手動実行：

1. **`initializeSheet`** — スプレッドシートにヘッダー行を作成
2. **`setupTrigger`** — 10分間隔の定期実行トリガーを設定
3. （オプション）**`importAllMails`** — 過去のヤフオクメールを一括インポート

> 初回実行時にGoogleからの権限承認ダイアログが表示されます。承認してください。

## ファイル構成

```
src/
├── main.gs     # エントリーポイント（トリガー実行、一括インポート）
├── config.gs   # 設定値（スプレッドシートID、ラベル名等）
├── gmail.gs    # Gmail検索・ラベル管理
├── parser.gs   # メール本文パース（正規表現処理）
├── sheet.gs    # スプレッドシート読み書き
└── utils.gs    # ユーティリティ（日付変換等）
```

## シート設計

| 列 | 項目 | 説明 |
|----|------|------|
| A | オークションID | 一意キー |
| B | 出品日時 | メールから自動取得 |
| C | 商品名 | メールから自動取得 |
| D | 開始価格 | メールから自動取得 |
| E | 終了予定日 | メールから自動取得 |
| F | 現在価格 | 入札時に自動更新 |
| G | 入札数 | 入札時に自動更新 |
| H | 落札価格 | 落札時に自動更新 |
| I | 落札者 | 落札時に自動更新 |
| J | ステータス | 出品中 / 落札済 / 未落札 / 取消 |
| K | 仕入価格 | **手入力** |
| L | 利益 | `=H-K`（自動計算） |
| M | メモ | **手入力** |

## メールパーサーの調整

実際のメールフォーマットに合わせて `src/parser.gs` の正規表現を調整してください。

### 調整が必要な箇所

- `classifyMail()` — 件名によるメール種別判定
- `extractAuctionId()` — オークションIDの抽出パターン
- `parseListingMail()` — 商品名・開始価格・終了予定日の抽出パターン
- `parseBidMail()` — 現在価格・入札数の抽出パターン
- `parseWinningMail()` — 落札価格・落札者の抽出パターン

### デバッグ方法

1. GAS エディタで `processYahooAuctionMails` を手動実行
2. 「実行ログ」で各メールの処理結果を確認
3. パースに失敗した場合はログに警告が出力される

## 注意事項

- ヤフオクのメールフォーマット変更時は正規表現の調整が必要です
- GASの実行時間制限（6分/回）があります。一括インポートは自動で分割処理されます
- `仕入価格`列と`メモ`列は手入力です。GASは上書きしません
